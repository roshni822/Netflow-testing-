# Audit log

The audit log records important actions in your organization — submissions, approvals, user changes, and more — for compliance and troubleshooting.

::: tip Who can view
Typically Manager-and-above report roles. If **Audit log** is missing from the sidebar, your role cannot open it.
:::

## Step 1 — Open the Audit log

1. In the left sidebar, under **REPORTS**, click **Audit log**.

   ![Audit log](/screenshots/guide/audit-log.png)

2. Wait for the first page of entries to load.

**You should see:** a timeline of actions with actor, action type, target, and time.

## Step 2 — Search and filter

1. Use the **search** box for target name or detail text.
2. Filter by **action** (approve, reject, submit, user changes, …).
3. Filter by **department** when needed.
4. Change **page** if there are many entries.

**You should see:** only matching rows — useful when investigating one request or user.

## Step 3 — Read an entry

1. Scan each row: **who** did **what** to **which target**.
2. Open related modules (Tasks, Forms, Admin) if you need the full record.
3. Note the timestamp for SLA or compliance questions.

## Step 4 — Export (optional)

1. Click **Export CSV** if shown.
2. Keep the file with your compliance pack.

## What gets recorded (examples)

- Form submitted / deleted  
- Task approved, rejected, escalated, submitted  
- Workflow started / completed / failed / cancelled  
- User invited, updated, deleted; role changes  
- Imports and other admin actions (as implemented)

The **Audit log** covers activity inside your workspace only.
