# Guide screenshots

PNG files in this folder are used by the public VitePress guides.

Current captures come from the running application. Gray masks protect private
values; no demo records or substituted role screens are used. Pending legacy
assets are retained for reference but are not embedded in the current guides.

Refresh instructions and the capture report are in `docs/screenshots.md` and
`docs/screenshots-report.json`. Never publish credentials or session tokens here.
